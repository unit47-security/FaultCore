# Security

FaultCore executes the command you provide. Use only programs and inputs you have reviewed, in a disposable environment appropriate to their risk. The runner is not a sandbox and does not isolate files, network or permissions.

Do not put secrets in public reports or issues. Diagnostic markers and command arguments may contain sensitive values. Share a minimal reproduction with versions, configuration and redacted logs. A private reporting channel has not been configured for this release; contact the repository maintainers before sharing sensitive details publicly.
