# FaultCore v0.1.0 — Lab MVP

UNIT-47's local crash reproduction, stability checking and signature-preserving input minimization tool.

- Bounded execution and explicit outcome classification.
- Repeated reproduction with conservative diagnostic signatures.
- Budgeted minimization with separate incomplete and final-failure states.
- Versioned JSON/text reports with artifact hashes and per-run evidence.
- Exclusive publication of output files; originals protected.
- ASCII FAULTCORE terminal identity, `--banner`, `--no-banner` and clean JSON output.

This source release is prepared locally, not published or tagged on GitHub. It targets laboratory fixtures, is not a sandbox, and does not claim confirmed vulnerabilities. Review docs/RELEASE-VALIDATION.md for the exact checks and remaining Linux release validation.
